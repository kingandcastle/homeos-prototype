# HomeOS Prototype 0.3.2 — TV Viewing Experience

Upload all five files to the root of the existing GitHub Pages repository, replacing earlier files. Visit https://kingandcastle.github.io/homeos-prototype/?v=032#iptv.

## New in 0.3.2
- Channel dropdown immediately beneath the Live TV player; uses your imported M3U list.
- Search within the tuner, favourites filter, and previous/next channel buttons.
- On-screen channel name/number banner displayed on tuning, automatically hidden after five seconds. Tap the video to reveal it again.
- Full channel browser collapsed by default to reduce scrolling; all existing channel management and diagnostics remain available.

The tuning banner does not claim to know programme information without imported EPG data. Playback still depends on source compatibility and provider access.
