# HomeOS Release Record

## 0.1.0 — 17 October 2026

**Status:** Functional browser prototype, not production software.

### Added
- Seven navigable modules: dashboard, IPTV, AI assistant, entertainment, app centre, smart home and settings.
- Responsive desktop/tablet/mobile interface with dark/light themes.
- Local data persistence, export and reset.
- M3U text import, channel search, favourites and browser video playback.
- Rule-based demonstration AI chat.
- Simulated household controls and scenes.
- Local video-file player and external entertainment links.
- Setup, acceptance-test and security documentation.

### Excluded intentionally
- OpenAI API integration, voice assistant, real smart-home control, native APK sideloading, native Android/iOS packaging, DRM integration, live EPG, accounts and cloud synchronisation.

### Release criteria
- Manual smoke tests listed in README.md.
- Any real-device or browser compatibility tests must be completed by the operator; not claimed as performed.
